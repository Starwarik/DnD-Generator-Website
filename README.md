Генератор Приключений — это сервис для автоматической генерации одностраничных приключений для настольных ролевых игр (НРИ), таких как Dungeons & Dragons. Генерация осуществляется при помощи нейросетевой модели GigaChat.

Репозиторий содержит:

    Бэкенд-приложение (API)

    Исходный код веб-сайта

Проект разработан в рамках реализации гранта Фонда содействия инновациям «Студстартап» (2023 год).

Релиз мобильного приложения: 16 октября 2025 года, RuStore.
