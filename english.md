# Description

**Adventure Generator** is a service for automatically generating one-page adventures for tabletop role-playing games (TTRPGs), such as Dungeons & Dragons. Generation is carried out using the GigaChat neural network model.

The repository contains:

*   Backend application (API)
*   Website source code

The project was developed as part of a grant from the Innovation Promotion Fund ("Studstartup", 2023).

**Mobile app release:** October 16, 2025, on RuStore.
